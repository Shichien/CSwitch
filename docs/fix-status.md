## 额外数据保护

- 崩溃恢复只还原本轮涉及的 SQLite 提供方字段，保留后来创建的任务、标题等用户字段。
- 新事务记录计划写入的配置及认证字节，恢复时识别中断后的外部修改，避免覆盖新状态。
- 支持 UTF-8 BOM 和合法的 TOML 内联表，保留用户表内字段。

## 后续复查修复

- 网关子进程创建后立即纳入生命周期管理。启动状态解析失败、进程提前退出或超时都会结束并回收未提交的进程；成功提交的子进程也有退出回收，避免 Unix 僵尸进程。
- 路由逐个读取和停止。单个状态文件损坏时保留该文件并报告路径，其余有效路由继续清理。
- 官方切换保留用户的 `model_catalog_json`，不再仅凭路径含有 CSwitch 目录就删除设置。
- 清理供应商旧快照前检查实时配置、官方快照、其他供应商快照及恢复备份里的模型目录引用。有引用的旧代次保留，引用解除后回收。删除供应商前检查外部引用；供应商自身即将删除的快照不构成外部引用。
- 供应商删除在注册表提交前中断时，下次更新先恢复原目录，避免产生新目录后与待删除目录冲突。
- 旧快照清理失败返回带具体路径的警告，列表仍然加载；前端沿用顶部三秒提示。鉴权开关及修改当前供应商时也传递切换后的清理警告。
- 恢复事务检查 `settings.json` 的外部修改，和配置、认证采用相同规则。发现冲突先保留所有当前文件与恢复记录。
- 正式写入配置、认证或设置前再次核对原值；同步期间出现外部修改时，保留用户新内容并回滚本次已修改的历史数据。
