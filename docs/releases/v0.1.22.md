# CSwitch v0.1.22

- 修复生成供应商模型目录时丢失思考等级，导致 Codex 思考强度显示为 none 的问题。模型编号与 Codex 本地缓存完全一致时，保留已知的思考等级、默认等级及思考摘要设置。
- 修复路由模式切换线路时，因模型目录变化而自动关闭 Codex 的问题。路由开启后切换官方或第三方线路，Codex 保持运行，新请求使用新线路，正在生成的请求继续完成。
- 模型选择列表需要刷新时，仅提示用户自行重新打开 Codex。首次启用、升级旧版路由、完全关闭路由，以及切换另一个官方账号，仍保留必要的关闭流程。
- 增加模型思考等级保留测试，并验证连续切换线路不关闭 Codex、不改动登录凭据及对话记录。

## 升级后操作

安装新版后，在 CSwitch 中重新应用当前供应商，再自行重新打开一次 Codex，让模型目录修复生效。之后在已开启的路由模式中切换线路，不会再因模型目录变化自动关闭 Codex。

未知模型编号不会凭空添加思考等级；实际支持能力由模型及供应商决定。
