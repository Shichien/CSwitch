# CSwitch v0.1.16

- 修复普通第三方切换后本地项目消失的问题。项目列表、顺序、根目录和聊天归属现在可以在第三方与官方账号间共享，普通第三方模式无需官方登录，重启 Codex 后仍保留。
- 已经出现项目消失时，更新后点击当前供应商卡片重新应用，再打开 Codex，即可从保留的账号状态恢复本地项目。
- 切回官方或切换官方账号时保留最新的项目修改，避免已删除的项目从旧快照重复恢复；各账号的云端缓存、远程连接和待执行任务保持隔离。
- 项目状态同步纳入自动备份、并发修改检查、失败回滚和中断恢复。即使供应商与聊天数据库没有变化，重新应用也会检查项目状态。
- 新增 10 项项目同步回归测试，覆盖重启、账号切换、删除保留、并发修改及中断恢复。

已核对 Windows Codex 桌面端 26.1103.4239.0 的实际状态切换逻辑。此功能共享本机项目，官方云端服务仍需要正常登录。更多边界见 [兼容性说明](https://github.com/Shichien/CSwitch/blob/v0.1.16/docs/compatibility.md#本地项目状态)。
