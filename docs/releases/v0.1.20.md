# CSwitch v0.1.20

- 修复 v0.1.19 将所有第三方模型标记为仅文本，导致 Codex 对支持图片的模型提示“此模型不支持图像输入”的问题。
- 生成模型目录时不再强制写入 `input_modalities: ["text"]`，沿用 Codex 未声明该字段时的文本与图片输入兼容行为。
- 重新应用供应商时会重新生成模型目录，清除旧版的错误限制，同时保留历史目录备份。
- 增加目录生成和旧目录迁移的回归测试。

## 升级后操作

安装新版后，在 CSwitch 中点击供应商卡片切换或“重新应用”，再重新打开 Codex。仅安装新版或仅点击“刷新模型列表”不会替换 Codex 当前引用的旧目录。

本次修复取消客户端错误的图片输入限制，不代表所有供应商模型都具备视觉能力；实际支持情况仍由模型和供应商接口决定。官方线路的模型目录恢复逻辑不变。
