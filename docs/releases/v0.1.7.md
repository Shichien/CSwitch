# CSwitch v0.1.7

## 更新

- 切换前关闭 Codex 并重新读取配置，保留退出时保存的自定义设置。
- 完善官方登录测活、令牌刷新和取消流程，避免重复登录操作互相干扰。
- 同步多个 SQLite 数据库；恢复时保留后来创建的任务和用户修改的字段。
- 写入配置、认证和设置前检查外部修改；失败时恢复本次修改。
- 保留用户模型目录设置，清理快照时保护配置和恢复备份仍在引用的文件。
- 完善供应商快照的成对提交、删除恢复和错误提示。
- 本地协议转换支持并发请求和实时流式输出，补齐网关进程回收及失败切换回滚。
- 修正工具调用、JSON Schema、流式截断检查及模型列表分页处理。
- 新增单实例唤醒，完善托盘、进度提示和模型列表刷新。
- 界面与文档统一为 CSwitch；旧版数据迁移继续保留。

## 下载

- Windows：按设备架构选择 x64 或 ARM64 安装包。
- macOS：通用安装包，适用于 Apple 芯片和 Intel Mac。
- Linux：按设备架构选择 x64 或 ARM64 的 AppImage、deb 安装包。

## 使用边界

- 第三方仅返回模型编号时，更新 CSwitch 内的模型列表；Codex 完整模型选择器还需要可信的完整模型元数据。
- 转换网关的 WebSocket、Responses compact、部分文件和音频能力尚未实现。
- macOS 签名和公证取决于发布证书配置；构建成功不代表完成公证。其他兼容性说明见仓库的 docs/compatibility.md。

发布前本地验证：112 项常规测试、1 项真实网关进程测试、Rust 格式检查、Clippy、前端与 Windows 程序构建均通过。各平台安装包由本次发布工作流分别构建。
