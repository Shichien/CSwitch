# CSwitch v0.1.19

- 每次切换第三方供应商（包括重新应用当前供应商）时，使用该供应商的 URL 和 Key 拉取模型列表，支持分页和去重。
- 将模型列表转换为 Codex 可读取的 `model_catalog_json`，重新打开 Codex 后可在模型选择界面选择供应商返回的模型。
- 普通切换和保留官方登录的路由模式均支持模型目录更新；目录变化时会关闭 Codex，并提示重新打开。
- 刷新失败时提示原因并保留已有模型列表。切回官方时恢复原模型目录设置，关闭路由时恢复对应的直接连接目录。
- 模型目录使用独立快照保存，避免后续刷新使历史配置备份失效。

## 使用说明

升级后点击供应商卡片切换或重新应用，然后重新打开 Codex。单独点击“刷新模型列表”只更新 CSwitch 保存的列表；应用到 Codex 请重新应用供应商。

通用模型接口仅提供模型编号时，不推断上下文长度或思考等级。模型可在界面中选择，不代表已经验证该模型的推理和工具调用能力。
