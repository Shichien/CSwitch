# CSwitch v0.1.11

## 更新

- 新增常驻本地路由：首次开启后重新打开 Codex，之后在官方和第三方之间切换线路，生成中的请求继续使用原线路。
- 路由明确使用 HTTP/SSE，保留官方登录态；第三方请求使用该供应商的 API Key。关闭窗口后驻留托盘，退出 CSwitch 时停止转发，重新启动后恢复原端口。
- 完善官方令牌保存、登录取消和连续点击互斥，切回直连前保存最新官方凭据。
- 自动导入当前配置中的自定义提供方，支持任意提供方编号、带引号的名称和内联配置，以及文件密钥和固定授权头。
- 普通第三方直连将 API Key 写入 auth.json；路由停用时恢复接管前的提供方、地址、传输和认证字段。
- 改善 Windows 进程退出等待和权限错误提示，保留退出时写入的最新配置。
- 修正长时间流式响应、上游鉴权错误和请求压缩处理；原生 Responses 路由支持 compact 与模型接口。
- 界面改为紧凑小窗，常驻路由开关置于左上角，供应商卡片与操作按钮并排。窗口随列表和表单内容调整高度。

## 下载与使用

1. 下载对应系统的安装包：Windows x64 或 ARM64、macOS 通用版、Linux x64 或 ARM64。
2. 更新前从托盘退出旧版 CSwitch，再安装并打开新版。
3. 点击官方登录使用现有登录态，或点击加号添加 API 供应商。
4. 使用常驻路由时保持 CSwitch 运行；首次开启、升级旧版路由或关闭路由后，重新打开 Codex。

macOS 签名和公证取决于发布证书配置。模型及协议支持范围见 [兼容性说明](https://github.com/Shichien/QuotaPlusPlus/blob/v0.1.11/docs/compatibility.md)。
