# CSwitch v0.1.23

- 紧凑展示官方额度：同时返回 5h 和 7d 时并排显示；只有一个额度窗口时占满一行，不显示空占位。
- 首次启动根据屏幕工作区与 DPI 选择窗口尺寸，首次内容适配的高度不超过工作区的 80%。
- 记住窗口大小、位置与最大化状态。显示器断开或 DPI 变化后，恢复时调整尺寸并确保窗口可见。
- 首次加载完成后保持窗口尺寸稳定，后续额度刷新不再触发自动缩放；加载期间手动调整窗口也会保留用户选择。
- 额度悬浮提示增加距离重置的剩余时间，同时保留准确日期；到达重置时间后提示刷新。
- 临时刷新失败时保留上一次成功查询的额度或余额，显示更新失败与数据更新时间，并支持重试。明确的授权失效仍会提示重新授权。
- 低额度增加图标与文字提示：剩余不超过 30% 提示额度偏低，不超过 10% 提示额度不足。

窗口状态独立保存，不影响账号和供应商配置。
