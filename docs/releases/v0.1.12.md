# CSwitch v0.1.12

## 更新

- 新增多个官方账号：点击右上角加号，选择添加 API 供应商或添加官方账号。官方账号通过浏览器 OAuth 登录，各自保存凭据，支持在卡片和托盘菜单中切换。
- 自动导入当前官方登录与旧版官方快照；重复登录同一账号更新凭据，添加账号时保留当前线路。
- 切换官方账号前关闭 Codex，保存其最后写入的凭据，再验证并启用所选账号；常驻路由保持原端口和配置。
- 修复重新登录后，新凭据被未变化的旧登录文件覆盖的问题，保留实际轮换后的最新令牌。
- 修复第三方对话切回官方路由时，消息 ID 格式不兼容引发的 Invalid input.id 错误；保留其他类型条目的编号。
- 修复 macOS Intel 上常驻路由测试中模拟服务器提前超时的问题。

## 使用

1. 从托盘退出旧版 CSwitch，再安装对应系统的新版本。
2. 点击右上角加号，选择添加官方账号，完成浏览器登录后保存；可继续添加其他账号。
3. 点击账号卡片或托盘菜单切换。切换到另一个官方账号后，重新打开 Codex。
4. 使用常驻本地路由时保持 CSwitch 运行。

安装包提供 Windows x64、Windows ARM64、macOS 通用版、Linux x64 和 Linux ARM64。
