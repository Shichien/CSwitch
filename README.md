# CSwitch

## 普通切换

- 关闭 Codex，读取并保存当前配置和登录凭据。
- 切到第三方：保留当前用户设置，将 `config.toml` 的提供方设为 `custom`，写入供应商名称、请求地址和认证设置；将 API Key 写入 `auth.json` 的 `OPENAI_API_KEY`。
- 切回官方：验证官方凭据，恢复官方配置和登录文件。
- 同步 `sessions`、`archived_sessions` 会话首行及 SQLite 中的提供方标识，保留对话正文。完成后重新打开 Codex。

## 常驻本地路由

- **开启**：保存原配置，将请求地址设为固定本地端口，使用 HTTP/SSE，并保留或恢复官方登录。官方提供方切为 `cswitch_local`，已有第三方提供方沿用原编号；提供方编号变化时，关闭 Codex 并同步对话记录。开启后重新打开 Codex。
- **切换线路**：更新代理出口。官方线路使用官方凭据，第三方线路使用对应 API Key；新请求走新线路，正在生成的请求继续走原线路。
- **关闭**：恢复启用前的提供方、地址和传输、认证设置，按提供方变化同步对话记录，然后重新打开 Codex。
- **运行**：关闭窗口后驻留托盘；退出 CSwitch 会停止转发，重新启动后恢复原端口。

## 切换官方账号

- 添加账号时通过浏览器 OAuth 登录并独立保存，当前线路保持原样；重复添加同一账号会更新凭据。
- 切到另一个账号时，关闭 Codex，保存原账号最新凭据，验证并写入所选账号。常驻路由沿用原端口和配置，完成后重新打开 Codex。

## 保存与备份

- 账号、供应商配置和路由状态保存在 `~/.codex/cswitch-profiles/`。
- 配置或对话迁移前备份本次涉及的配置、认证、会话首行和 SQLite，保存在 `~/.codex/cswitch-backups/`，最多保留十份。
- 修改失败时回滚本次操作；重启后处理未完成事务。
