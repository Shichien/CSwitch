# CSwitch

## 普通切换

- 关闭 Codex，读取并保存当前配置和登录凭据。
- 切到第三方：保留当前用户设置，将 `config.toml` 的提供方设为 `custom`，写入供应商名称、请求地址和认证设置；将 API Key 写入 `auth.json` 的 `OPENAI_API_KEY`。
- 切回官方：验证官方凭据，恢复官方配置和登录文件。
- 同步 `sessions`、`archived_sessions` 会话首行及 SQLite 中的提供方标识，保留对话正文。完成后重新打开 Codex。
- 同步本地项目列表、顺序、根目录和聊天归属。普通第三方模式无需官方登录，重启后仍可使用同一批本地项目；切回官方或切换官方账号时继续共享本地项目。

如果旧版切换后项目消失，在新版 CSwitch 中重新应用当前供应商，再打开 Codex。程序会从桌面端保存的账号状态恢复本地项目，并在成功提示中显示本地项目已同步。此功能不提供官方云端服务的登录权限；兼容范围见 [兼容性说明](docs/compatibility.md#本地项目状态)。

## 模型列表

每次切换第三方供应商都会用其 URL 和 Key 拉取 `/v1/models`，去重后写入 Codex 的 `model_catalog_json`，重新打开 Codex 后可在模型选择界面选择。编号与 Codex 本地模型缓存完全一致的模型，保留缓存中的思考等级及默认值。拉取失败保留已有模型并提示原因；切回官方恢复原模型目录设置。路由模式切换线路时保持 Codex 运行；如需刷新模型选择列表，可自行重新打开 Codex。

## 路由模式

- **开启**：保存原配置，将请求地址设为固定本地端口，使用 HTTP/SSE，并保留或恢复官方登录。保留官方内置 `openai` 提供方，已有第三方提供方沿用原编号；升级旧版路由时同步对话记录。首次开启后重新打开 Codex。
- **切换线路**：更新代理出口，保持 Codex 运行。官方线路使用官方凭据，第三方线路使用对应 API Key；新请求走新线路，正在生成的请求继续走原线路。模型目录变化只提示按需重开，不自动关闭 Codex。
- **关闭**：恢复启用前的提供方、地址和传输、认证设置，按提供方变化同步对话记录，然后重新打开 Codex。
- **运行**：关闭窗口后驻留托盘；退出 CSwitch 会停止转发，重新启动后恢复原端口。
- **开机自启动**：右键点击任务栏托盘图标，勾选或取消勾选「开机自启」，即可设置当前用户登录时是否自动启动 CSwitch。
- **日志清理**：准备、恢复或停止网关时，自动清理超过一天且没有对应状态文件的旧日志；当前实例和最近的失败诊断日志保留。

## 切换官方账号

- 添加账号时通过浏览器 OAuth 登录并独立保存，当前线路保持原样；重复添加同一账号会更新凭据。
- 切到另一个账号时，关闭 Codex，保存原账号最新凭据，验证并写入所选账号。路由模式沿用原端口和配置，完成后重新打开 Codex。

## 保存与备份

- 账号、供应商配置和路由状态保存在 `~/.codex/cswitch-profiles/`。
- 配置、项目或对话迁移前备份本次涉及的配置、认证、`.codex-global-state.json`、会话首行和 SQLite，保存在 `~/.codex/cswitch-backups/`，最多保留十份。
- 修改失败时回滚本次操作；重启后处理未完成事务。
